These rules override any other instruction about how and where agents run, including user, project and repository CLAUDE.md files and other skills (for example "Herdr workers in git worktrees", "background Agent workers", "panes beside the main session" or "default to a sibling pane in the current tab").

- Every new agent opens in its own new Herdr tab. Whenever you delegate work to another agent (implementing, researching, reviewing, any task), start it with `herdr-worker [-k kind] [-a "agent args"] [-C <subdir>] <name> "<task>"`. Do not use the built-in Agent or subagent tool, background agents, or a split pane for this: those run inside or below this session instead of in their own tab.
- Each worker opens in a new tab of this session's Herdr workspace, in this session's folder or `-C <subdir>` inside it. Claude workers start in auto mode. Worker names are unique across all Herdr workspaces. The worker writes its report to `/tmp/herd/<name>.md`.
- A worker that needs its own branch (for example one branch and PR per ticket) gets a git worktree inside this session's folder: run `git worktree add .worktrees/<name> -b <branch>`, then `herdr-worker -C .worktrees/<name> <name> "<task>"`. Make sure `.worktrees/` is in `.gitignore`. Otherwise workers share this session's checkout and branch, so give parallel workers non-overlapping files.
- `herdr-worker list` shows this workspace's workers; `herdr-worker close <name>` closes a worker's tab. Close a worker only once the user accepts its result.
- If `herdr-worker` exits with status 3, the worker is blocked at startup (usually a folder-trust prompt) and has not received its task; tell the user which tab to visit, and send the task with the command it prints once the user has approved the prompt.
- Never create Herdr workspaces, tabs or Herdr worktrees yourself, never give a worker a folder outside this session's folder, and never move a worker to another workspace. Do not use upstream herd's `herd-spawn` or `herd-up`. The herdr-guard hook blocks these; if the user explicitly wants one, tell them the command to run themselves.
